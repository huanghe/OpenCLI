# AI 创业公司参考 


1. **具身智能 / 机器人**：机器人感知（CV 直接复用）、实时视频流传输、遥操作（teleoperation）链路、边缘端 C++ 部署。这是当前融资最热的赛道，且极缺能写高性能 C++ 的工程师（大部分候选人只会 Python 调模型）。
2. **实时互动视频 / AI 数字人直播**：WebRTC + 生成模型推理流水线，流媒体经验是硬门槛，会的人极少。有公司 1 年内估值破 10 亿美金。
3. **视频生成（Video Gen）/ AI 影视**：推理加速、视频编解码、渲染管线，C++ 性能优化是核心岗。
4. **自动驾驶 → 具身智能迁移团队**：整个技术栈（C++ / 感知 / 实时系统）无缝对接。
5. **AI 硬件（眼镜 / 相机 / 玩具）**：端侧 CV + 视频链路，嵌入式 C++。

**面试叙事建议**：不要把自己定位成"传统 CV 工程师"，定位成"能把 AI 模型跑进实时视频链路的系统工程师"——这是初创公司 CTO 最想要但招不到的人。

## 五、怎么建联（实操建议）

1. **小红书网页端没有私信功能**，私信必须在手机 App 上发。
2. 推荐路径：**先在对方最近的招人帖/创业帖下留一条有信息量的评论**（一句话说清自己是谁 + 能解决什么问题），再关注，再 App 私信。创始人几乎都会看自己帖子的评论。
3. 私信模板（示例，按对象微调）：
   > 你好，看到你在做 XX。我做了 6 年 C++/流媒体/计算机视觉，之前在 XX 公司负责 XX（实时视频链路 / 模型端侧部署 / 性能优化），对你们的 XX 方向很感兴趣，方便聊聊吗？可以先发简历。
4. **优先级**：第二节「正在公开招人的」> 具身智能/AI 视频方向创业者 > 其他。招人帖有时效性，越早的帖子越可能已招满，2026 年 5-6 月的帖子优先。
5. 除了小红书，这些团队大多同时在 BOSS 直聘/即刻/内推群招人，小红书私信的优势是**直达创始人本人**，绕过 HR 筛选——对 6 年经验想进早期团队做核心的人来说，这条路径成功率更高。
